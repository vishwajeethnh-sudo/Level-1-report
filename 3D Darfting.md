## Task 1: 3D Drafting 
### Objective
The objective of this task is to create 3D models of at least three machine parts in Solidworks using the reference drawings provided.

### Procedure
I studied the supplied engineering drawings, identified the main dimensions and features, and created the corresponding parts in Solidworks using suitable modelling operations. I checked the models against the references to ensure that the main geometry was represented correctly.
