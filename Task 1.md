## Task 1 - Deign of Allen Key
### Objective

The objective of this task is to create a 3D Allen key model in CAD and generate a labelled engineering drawing using the given parameters.

Procedure

I created the Allen key geometry in Solidworks using the specified dimensions. I developed the 3D model using suitable modelling tools and generated a drawing with the required labels and dimensions.

Parameters

Length: 55 mm

Width: 20 mm

Size: 3 mm

Learning

This task helped me understand how to create a simple mechanical tool as a 3D model and prepare a corresponding engineering drawing in Solidworks.
